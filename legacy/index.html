A few things to know.

Is this the actual browser extension?

No. This is a standalone demonstration of PageGuide's Find and Guide interactions on a local, fictional replica of an arXiv abstract page, with scripted responses by default and optional live OpenAI-powered answers. It does not read other tabs, open the real arXiv, or control your browser.

Which paper is this?

The demo page recreates the arXiv listing for “PageGuide: Browser extension to assist users in navigating a webpage and locating information” (arXiv:2604.23772, cs.HC) — the paper that introduces PageGuide. So you're running a model of PageGuide on the page that describes it.

Can I ask any question in the playground?

Simulation mode recognizes a small set of topics from the abstract and uses pre-written responses. Use the suggested prompts for the full experience, or connect your own OpenAI API key below the playground for live Find and Guide. Live answers may be inaccurate; always check the highlighted source.

What can the real extension do?

PageGuide grounds an LLM's answers in page content — DOM elements, text, maps, images, and charts. FIND highlights the supporting evidence for an answer; GUIDE walks you across a page's steps while capturing evidence along the way. In a study with 92 participants it raised verification accuracy from 65% to 77%.

Does the real extension need setup?

Yes. The extension supports Chrome and Edge and uses your own API key with a supported provider (such as Google Gemini, OpenAI, or OpenRouter). That setup is not needed for this simulated playground. The code is publicly available at github.com/tinxai/pageguide.
