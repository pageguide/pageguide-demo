A few things to know.

Is this the actual browser extension?

No. This is a standalone demonstration of PageGuide's core interactions, with scripted responses by default and optional live OpenAI-powered Find and Guide. It works only on the fictional pages inside this demo; it does not read other tabs or control your browser.

Can I ask any question in the playground?

Simulation mode recognizes a small set of topics and uses pre-written responses. Use the suggested prompts for the full experience, or connect your own OpenAI API key below the playground for live Find and Guide. Live answers may be inaccurate; always check the highlighted source.

What can the real extension do?

PageGuide can find and highlight answers, guide you through tasks, hide distracting elements, match an image on a page, and answer questions about PDFs. With page context off, it can also answer general-knowledge questions.

Does the real extension need setup?

Yes. The extension supports Chrome and Edge. It requires installation and configuration of a supported AI provider with an API key. That setup is not needed for this simulated playground. Actual extension data handling depends on your selected provider and configuration.
